# 💻 DeskHub

DeskHub is a desktop producktivity dashboard buith with Electron , HTML , CSS , JavaScript and a cup of coffee , for the Hack Club **Macondo** YSWS Event.

## Features

- A live clock and date
- Dynamic Greeting
- Sticky Notes (Auto Save)
- Today,s Focus (Auto Save)
- Task Manager

## Built With
 
- Electron
- HTML
- CSS
- JavaScript


## Getting Started

Clone the repo

```bash
git clone https://github.com/YOUR_USERNAME/DeskHub.git
```

Install Dependencies

```bash
npm install 
```

Run the app

```bash
npm start
```
